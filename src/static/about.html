O problema

Empresas possuem dados espalhados em vários bancos. Acessar exige ferramentas diferentes, conhecimento técnico, e ninguém sabe o que está acontecendo em tempo real.

Dados fragmentados

PostgreSQL aqui, MySQL ali, planilha acolá. Nenhuma visão unificada.

Dependência técnica

Para tirar um dado simples, precisa de um analista ou desenvolvedor.

Sem alertas

Ninguém é notificado quando algo importante acontece. Problemas são descobertos tarde demais.

A solução: Data Hub

Uma única plataforma que conecta seus bancos, interpreta perguntas em linguagem natural e monitora seus dados automaticamente — enviando alertas no Telegram, WhatsApp, Slack ou Teams.

Pergunte em linguagem natural

"Quanto vendemos hoje?" — o sistema interpreta, gera a query e responde.

Alertas automáticos

Configure regras e receba notificações quando algo precisar de atenção.

Multi-banco

PostgreSQL, MySQL, SQLite, MongoDB e APIs REST — tudo em um lugar.

Multi-canal

Telegram, WhatsApp, Slack, Google Chat e Teams. Acesse de qualquer lugar.

Como funciona

Fluxo simplificado: você pergunta, o sistema entende, consulta o banco e responde — tudo automático.

💬

Você pergunta

No Telegram, WhatsApp, Slack ou na web: "Quanto vendemos ontem?"

🧠

IA interpreta

O modelo (9router) entende a intenção, pega o schema do banco e gera SQL seguro (apenas SELECT).

🗄️

Consulta o banco

Executa a query no PostgreSQL, MySQL, SQLite, MongoDB ou API REST configurado.

📊

Responde formatado

Devolve a resposta no mesmo canal: tabela, número ou texto — do jeito que você pediu.

Casos de uso

1. Monitoramento de estoque

Gerente quer ser alertado quando estoque cair abaixo de 10 unidades.

"Me avise quando estoque do Produto X cair abaixo de 10"

2. Relatório diário de vendas

Diretoria recebe resumo das vendas todo dia às 8h no Telegram.

"Quanto vendemos ontem? Me envia todo dia às 8h"

3. Alerta de faturamento

Time financeiro é notificado no Slack quando faturamento ultrapassar R$ 100k.

"Avise no Slack quando faturamento > 100.000"

4. Consulta via WhatsApp

Vendedor em campo pergunta estoque pelo WhatsApp e recebe resposta em segundos.

"Qual o estoque do Produto Y?" → Resposta via WhatsApp

5. Alerta de metas

Marketing é notificado quando banco atingir 1.000 clientes cadastrados.

"Avise quando tivermos mais de 1.000 clientes"

6. Agendamento flexível

Alertas rodam a cada X minutos, horas, dias — ou em horários específicos via cron.

Todo dia às 08:00 · Toda segunda · A cada 30 min

Por que essas escolhas?

Python + FastAPI

Performance assíncrona, documentação automática, ecossistema rico de bibliotecas de dados.

Docker

Um comando para subir tudo. Funciona igual em qualquer máquina.

LiteLLM + 9router

Interface única para qualquer provedor de IA. Sem lock-in. Troque o modelo sem mudar código.

Redis

Cache ultrarrápido + rate limiting com sliding window. Essencial para APIs.

Telegram + WhatsApp

Os dois canais mais usados no Brasil. Bot do Telegram gratuito. WhatsApp via Evolution API self-hosted.

Loki + Promtail

Logging estruturado JSON com correlation IDs. Integrado ao Grafana para dashboards.

Funcionalidades

Intent Engine

Regex para respostas rápidas, LLM como fallback para perguntas complexas.

Frontend SPA

Painel web inspirado no Linear. Dark theme, i18n PT/EN.

JWT Auth

Autenticação completa com tokens. Credenciais configuráveis.

Rate Limiting

Sliding window via Redis. 3 tiers: geral, LLM e auth.

Structured Logs

JSON com correlation IDs. Pronto para Loki/Grafana.

Alertas com Cron

Intervalo ou agendamento. Minutos, horas, dias — ou expressão cron.
